# Analyse Croisée des Cours RP Zenkai

## 1. Entités Récurrentes Identifiées

### 1.1 Les 12 Mudras
Définis dans `Mudras.docx`, ce sont des gestes qui permettent de modeler le chakra. Sans mudras, le chakra est instable (jutsu ratés). Ils servent à canaliser, transformer et stabiliser le chakra. L'exécution doit être précise, rapide et fluide — l'ordre est crucial et ça doit être instinctif.

| Mudra | Fonction dans le flux de chakra |
|-------|----------|
| Rat | Initie la mise en mouvement du chakra |
| Bœuf | Donne une structure au chakra et empêche la technique de se disperser |
| Tigre | Amplifie et intensifie le flux |
| Lièvre | Fluidifie le flux |
| Dragon | Concentre le chakra sous une forme dense |
| Serpent | Apporte la précision |
| Cheval | Intensifie et accélère le flux |
| Bélier / Chèvre | Équilibre et harmonise |
| Singe | Coordonne les enchaînements complexes |
| Coq / Oiseau | Projette et dirige |
| Chien | Protège et structure en défense |
| Sanglier / Cochon | Permet une libération plus brutale du chakra |

### 1.2 Natures de Chakra (5 élémentaires)

| Nature | Force spéciale | Supérieur à |
|--------|---------------|-------------|
| Katon (Feu) | Brûlures | Futon |
| Futon (Vent) | Vitesse de déplacement | Raiton |
| Raiton (Foudre) | Étourdissement | Doton |
| Doton (Terre) | Robustesse | Suiton |
| Suiton (Eau) | Absorption de chakra | Katon |

### 1.3 Kekkei Genkai (combinaisons avancées)
Bakuton, Deiton, Futton, Hyoton, Jiton, Mokuton, Shakuton, Yoton, Ranton. Plus le Kekkei Tōta : Jinton (3 natures).

### 1.4 Hiérarchie Ninja (rangs)
Apprenti Genin → Genin → Genin Confirmé → Chūnin → Konin → Tokubetsu Jōnin → Jōnin → Commandant Jōnin → Sanin → Hokage

### 1.5 Techniques de Combat (Taijutsu)
- **Bourrasque de Konoha** (`bourasque.docx`) : Coup de pied rotatif 360°
- **Pied de l'Aube** (`pied de l'aube.docx`) : Technique de saut offensif
- **Saut de Chakra** (`saut de chakra.docx`) : Propulsion par concentration du chakra dans les pieds

### 1.6 Techniques Raiton (Ninjutsu)
Définies dans `cours raiton.docx` : Rayon Instantané, Boule Fulgurante, Ruée Foudroyante, Zone Fulgurante. Chacune avec ses séquences de mudras.

### 1.7 Armes Ninja
Catalogue dans `arme ninja.docx` : Katana, Makibishi, Clochettes, Bombe fumigène, Parchemin explosif, Senbon, Kunai, Shuriken.

### 1.8 Philosophie / Doctrines

## 3. Points d'attention

### 3.1 Cours sans fichier source .docx
- **Décomposition du Chakra** : existe uniquement dans le HTML/JSON, pas de .docx
- **Permutation** : existe uniquement dans le HTML/JSON, pas de .docx

### 3.2 Séquences de Mudras
Le cours `Mudras.docx` explique chaque mudra individuellement mais ne donne pas de séquences pour des jutsu spécifiques. Les séquences de mudras sont détaillées dans `cours raiton.docx` (Serpent→Lièvre, Dragon→Serpent, etc.) et dans `saut de chakra.docx` (Rat→Bélier→Tigre).

### 3.3 Public cible
La plupart des cours théoriques visent les Apprentis Genin. Les cours pratiques varient :
- Apprentis Genin : orientation, pays du feu, infiltration pratique
- Genin : taijutsu, saut de chakra, traque, enquête, jeu du roi, capture de drapeau, escorte, simulation mission
- Genin Confirmé : analyse de combat par nature, techniques Raiton avancées, permutation
